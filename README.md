# Café Aroma – App de pedidos anticipados

## Descripción
Aplicación móvil de pedidos anticipados para Café Aroma, con panel de recepción para
sucursal y backend en la nube. Permite a los clientes ordenar y pagar su consumo antes
de llegar al local.

## Objetivo
Reducir las filas y los tiempos de espera en las ocho sucursales de Café Aroma, sin
eliminar la atención en caja.
